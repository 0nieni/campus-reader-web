# 网页提醒

本版范围：站内提醒、ICS 日历导出、标准 Web Push；支持人工确认的截止时间及学校／标题关键词关注。邮件提醒和自动 AI 日期提取不在本版范围内。

## 使用方式

- 公告详情点击“设置提醒”，填写事项和北京时间，选择提前7天、3天、1天、到时。已经过去的提前档位不再创建；全部已过去会要求重新选择。无须先收藏，不调用模型或扣 AI 次数。
- 左侧“提醒”查看未读通知、全部时间提醒和关注规则。支持编辑、取消、标为已读、打开原公告及导出单条／全部未来提醒。
- 关注当前学校列表，可选一个标题关键词；每条规则独立。只有添加关注后新入库且仍授权可读的公告会提醒，旧记录更新不会重复提醒。不读取正文做关键词推测，也不额外采集官网历史页；学校列表可能包含通用竞赛来源。
- 新公告提醒依赖实际采集入库。后台提醒检查不等于后台刷新所有学校／个人来源；原有选校刷新、一小时缓存和每日最多三校预采集边界保持不变。
- 网页可见时最多每5分钟检查一次，恢复前台至少间隔1分钟；接近本人已设提醒时缩短下一次检查等待。标签和通知保存在本人账号，不写浏览器 Storage，不在 Service Worker 中缓存网页、账号令牌或公告正文。
- 离线跨过多个提醒点时合并为最近的一条，避免集中补发。关闭网页后的浏览器推送每天北京时间09:00、20:00检查，可能晚于所设时刻，不保证准点或设备送达。
- ICS 使用 UTC 时间及 VALARM。实际系统提醒取决于导入的日历和系统设置；网页编辑／取消不会自动更新已导入的日历，需要在日历中同步修改。文件由用户保管。

## 浏览器推送

用户在“提醒中心”主动开启并授予通知权限后，浏览器注册不含缓存逻辑的推送 Worker。每账号最多5个浏览器，端点全局唯一绑定一个账号。退出登录时注销当前浏览器订阅；关闭推送不删除站内通知。

iPhone／iPad 需使用支持 Web Push 的系统并把网站添加到主屏幕，再从主屏幕打开。内嵌浏览器、网络限制、系统通知权限或省电设置可能影响推送；界面检测能力并保留站内／日历入口。[Apple Web Push 说明](https://webkit.org/blog/13878/web-push-for-web-apps-on-ios-and-ipados/)

推送只包含“你有新的提醒，请登录提醒中心查看”，不含学校、公告标题、私人来源或用户标识。点击打开登录后的提醒中心。服务端先保存站内通知，再加密签名发送通用摘要；每设备每批合并一次。推送服务接收不等于设备显示。

推送尝试先持久化认领，重复检查不重发；未知或失败结果不自动重试，避免重复打扰。404／410 端点删除。新启用设备不补发此前消息。取消提醒或关注会停止尚未开始的新推送；已经交给系统的通知可能仍显示。测试通知每设备每分钟一次，只发给当前账号绑定的端点。

## 数据、额度与部署

- 每账号最多100条时间提醒、10条关注规则。站内通知显示最近90天、最多200条。
- 新迁移 `20261020000100_web_reminders.sql` 新增账号状态、公告到达记录、关注去重和推送设备表；不修改四份已应用迁移，也不回填旧公告到达记录。
- 到达记录仅存公告ID和到达时间。查询复用列表的 SQL 可见性条件，并再次按真实账号和学校复核；读取、导出和推送前重验公告状态／保留期。个人标签不扩大权限。
- 现有每日清理优先清除 AI 过期资料，再清90天到达／去重记录和旧提醒，及180天未续订设备。按访问与每日任务清理，不承诺无人访问时精确秒级物理删除。
- 新函数 `reminders.mts`：UTC `0 1,12 * * *`。每轮最多20个已订阅账号，按上次检查时间轮换，18秒软预算、每网络请求3.5秒硬截止、每账号最多5个设备并发；平台执行上限仍为30秒。规模增长时需重新评估调度与资源，不能承诺无限用户准点推送。
- `WEB_PUSH_PUBLIC_KEY`、`WEB_PUSH_PRIVATE_KEY` 只配置于 production 的 Functions scope；私钥不可进入 VITE 变量、源码、日志或客户端。VAPID subject 固定本站网址。预览环境禁用真实推送，定时任务仅生产发布后运行。
- 没有付费升级、邮件服务、用户邀请、真实模型调用或生产用户资料读取。保留官方 AI 每账号每天3次和 BYOK。

## 验证

自动回归使用临时本地 SQL、合成账号和推送桩，覆盖权限、跨校编辑、日期验证、并发去重、取消／改期、新公告50条以上续查、未知推送不重试、失效设备清理、日历UTF-8折行、真实 Web Push 加密签名、前端主动授权与异步结果隔离。

本地浏览器使用真实 Vue App 和合成传输，在1366×900、1000×620、390×844、360×640检查提醒设置、关注、标已读、日历下载、各页滚动及无横向溢出；单独触发 Worker 验证通用通知显示。证据位于忽略的 `.migration-private/web-reminders/`，`qa/` 和凭据均不发布。

真实手机的系统权限、关闭网页后的厂商推送链路和下一次09:00／20:00生产调度，需要上线后由用户主动开启并验收；本地组件验证不代表真实设备已收到推送。
