# DeepSeek 搜索整合与发布

用户确认：将 DeepSeek Search / Fetch 整合到最新正式版并上线；所有账号统一复用网站后台的官方 DeepSeek Key，沿用原有搜索限额。实现基于 main `a69ad84`，保留 PR35 的自然搜索、个人服务商、多轮对话、记忆、权限核验和提醒功能。

## 当前行为

- 聊天中的明确搜索、自然校园资料搜索与侧栏“联网找资料”均使用 DeepSeek；“你能联网吗”和侧栏状态依据同一个配置检查。
- 复用 `AI_CHAT_API_KEY` 与官方 `AI_CHAT_BASE_URL`，个人聊天 Key 不参与搜索，不新增服务商账号、依赖、迁移或函数。旧 Tavily 适配器仅保留兼容回归。
- 每账号每天最多 20 次、至少间隔 15 秒；一次 Search 取最多五条线索，新读取前三条正文。Search 与 Fetch 按供应商请求计量，失败或空结果不会伪装为有新资料。
- 保留来源许可、撤回记录核验、公网 DNS、robots 与重定向检查。候选摘要不作正文证据；新正文仍为账号和学校隔离的 24 小时临时资料，不创建来源订阅。
- Key 仅发往固定官方接口；后台地址不是 DeepSeek 时拒绝复用，避免把中转或其他服务商凭据发给 DeepSeek。

## 本地验证

915 项测试通过（前端 300、后端 615），包含新增官方配置、Search / Fetch 请求、错误分类、超时、robots、公网 DNS、跳转限制，以及默认生产接线和临时证据保存。类型检查、普通构建和 16 函数 Netlify 完整构建通过。没有修改依赖锁、历史迁移或提醒发送逻辑。

已只读确认 Netlify 当前登录账号和既有正式站点。CLI 返回的 secret 隐藏占位可导致本地请求 401；这不是线上真实 Key 无效的证据。未导出或保存真实密钥。发布和站内真实验证的结果在操作完成后单独记录。
