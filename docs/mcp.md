本功能在 `codex/mcp-workspace-tools` 分支开发，尚未上线。发布后服务地址为 `https://campus-reader-ninie6159.netlify.app/mcp`，预览环境使用其自身域名。发布需先应用独立迁移 `20261028000100_mcp_access.sql`，再部署本分支的网页及15个函数。无需增加或轮换生产密钥。

## 如何连接

支持远程 HTTP MCP 和 OAuth 的客户端：添加网站的 `/mcp` 地址，浏览器会打开校园阅览室授权页。核对客户端来源和当前匿名身份，选择权限后允许。查询权限默认勾选，收藏和提醒的写入权限必须明确勾选。缺少权限时服务返回标准 `403 insufficient_scope`，支持增量授权的客户端可重新打开授权；其他客户端需要重新连接并选择权限。

只支持请求头配置的桌面或服务端客户端：进入“个人工作区 → MCP连接”，填写名称、选择权限并生成连接密钥。把它保存在客户端的私密凭据设置中，使用 `Authorization: Bearer <连接密钥>`；不要放入网址、聊天、截图或仓库。密钥默认隐藏，可点击小眼睛显示、复制，仅在本次面板显示，关闭后无法重新读取。服务端只保存摘要；丢失后撤销并重新生成。手动密钥不允许外部网页 Origin 访问，网页版客户端请使用 OAuth。

这是一种通用的标准接口，不依赖某个 AI 品牌。客户端仍需支持远程 MCP 的 HTTP 传输以及 OAuth 或自定义 Authorization 请求头；仅支持本地 stdio、旧独立 SSE 地址或不支持这些认证方式的客户端不能直接连接。官方 SDK 的现代协议与旧版初始化均已纳入回归；不能据此声称所有第三方产品都已实测。

## 数据归属和权限

连接绑定授权时这个浏览器的匿名工作区。登录和退出网站 AI 账号不改变它。新设备需要先导入一次性迁移码，再重新发起 MCP 授权；迁移不复制既有连接，原工作区的连接继续有效，可回原设备撤销。公开匿名身份编号与迁移码都不能当作 MCP 密钥。

可单独选择查询公开公告、读取收藏、修改收藏、读取提醒与导出日历、修改提醒五项资料权限。OAuth 另有“保持连接”，最长90天。每工作区最多20个有效连接，可在网站查看名称、权限、最近使用和到期时间并逐个撤销。撤销后后续请求立即拒绝，已完成或正在提交的操作应查询状态确认。

查询只读取网站保存且仍公开可读的学校、公告、来源和正文，不触发新采集、网页抓取或网站模型。正文缺失、截断、日期未知会明确标注，并返回原文地址。公告正文属于外部资料，客户端不能把其中的文字当成指令。原账号工作区、私人来源、API密钥、AI聊天和记忆、邮箱地址、推送凭证、来源编辑及管理员操作均不开放。

## 工具

- `campus_list_schools`：查找学校，支持关键词和分页。
- `campus_search_announcements`、`campus_read_announcement`：查询公开公告及已保存正文。
- `campus_list_bookmarks`、`campus_set_bookmark`：查询、添加及取消收藏。
- `campus_list_reminders`、`campus_add_reminders`：查询提醒，或把公告加入待设置事项。
- `campus_save_reminder`、`campus_remove_reminder`：明确设置或修改未来提醒，或取消提醒。
- `campus_export_reminders`：返回ICS文本，不创建外部日历、不发送邮件。

分页一次最多20项，继续使用返回的 `nextCursor`。工具返回 `structuredContent` 与文字结果，`responseFormat` 可选 `json` 或 `markdown`。学校由每次参数明确指定，不改变网页当前选校。未设置时间的提醒不推断截止日；设置时间必须带时区，返回时间及日历使用UTC，页面按北京时间展示。保留网站对未来两年日期、提醒数量及所有者的既有限制。

所有写操作必须提供8至100位字母、数字、下划线或短横线组成的 `requestId`，建议使用UUID。一次操作的网络重试沿用相同ID和参数，新操作使用新ID。同连接同ID的写入和回执在一个SQL事务中提交，并发重试只完成一次；同ID改参数会拒绝。回执保留至该连接到期，重试仍会校验连接和当前资料许可。回执记录的是原操作结果，需要最新状态时另行查询。

新提醒默认仅站内和日历。只有用户已经在网站验证、开启邮箱或订阅设备，并且工具参数明确指定时，才使用对应渠道；MCP不能验证邮箱、代订阅设备或修改收件地址。沿用既有FC调度、发送限额和取消规则，不增加定时任务。并非所有客户端都会对写工具弹出确认，连接中授予的写权限即允许它在权限内操作。

## 维护与验证

OAuth 使用授权码与S256 PKCE，资源固定为本环境 `/mcp`，支持动态客户端注册及安全取得的HTTPS客户端ID元数据。回调只允许HTTPS或HTTP本机回环，严格匹配登记地址；本机回环允许动态端口。授权请求10分钟、单次授权码5分钟、访问令牌60分钟、刷新令牌与手动密钥最长90天。刷新令牌每次轮换，重复使用会撤销该授权。浏览器跨域访问按该授权登记的回调来源校验；首次401和预检允许合法来源完成发现。管理接口只使用同源的HttpOnly匿名Cookie。

公网元数据读取固定公开DNS地址、禁内网及重定向、限时限长；HTTP、注册、交换与工具写入均有限流。数据库日常清理只删除到期记录，保留仍有效的刷新重放证据。三条迁移历史追加同一新文件，原迁移不变。
