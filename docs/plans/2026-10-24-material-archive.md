# 采集资料库实施计划

用户已确认：公告正文与 PDF、Word（doc/docx）、Excel（xls/xlsx）附件按现有学校、来源及权限规则入库；保存 365 天，原文件和提取文本一起到期；每天一次采集近 30 天使用过的学校及启用个人来源；文字型文件自动提取，扫描 PDF 保留原件并明确无可提取文本。提醒功能不改动。

## 实现与边界

- [x] Postgres 保存索引、提取文本、有效期和任务租约；Netlify Blobs 保存原文件，生产与预览隔离。保留公告 ID、收藏、个人标签及提醒关联。
- [x] 公开下载校验学校域名、每次跳转和公网 DNS，固定连接地址；不携带账号 Cookie，不绕过登录或验证码。单个附件最多 10 MiB；只解析允许格式，宏、脚本、外部链接均不执行。
- [x] 在可终止的 Worker 中提取 PDF / Word / Excel；限制 ZIP 展开量、页数和输出字符。保留原文件，扫描件、加密件或超限状态如实展示，不能把截断/失败当作完整正文。
- [x] 详情与 AI 资料读取自动使用库中有效文本，缺失或过期时重新采集。临时 AI 搜索仍遵守原 24 小时限制，不能扩展为一年。
- [x] 每日采集通过独立的定时入口与后台任务完成；新服务端触发密钥仅经环境变量配置。任务在数据库中去重、加租约、断点续跑，并限制单次运行时间。不开启第三方 OCR，不调用模型。
- [x] 读取时立即排除过期资料；每日清理删除过期 Blob 和提取文本。失败可恢复且不能误删并发写入的新版本；公告和提醒记录保留。
- [x] 页面显示保存有效期、附件提取状态及鉴权下载；更新 AI 资料清单的附件说明，保持原日额度、来源复核和会话到期规则。
