# 通用 MCP 与匿名工作区授权

用户选择：外部 AI 可查询公告并操作本人收藏和提醒，面向通用 MCP 客户端。沿用匿名工作区作为数据归属，登录仍只解锁网站 AI。本轮在 `codex/mcp-workspace-tools` 完成实现与验证，发布另行记录。

## 交付

- `/mcp`：官方 TypeScript SDK 2.4，Web Request/Response、无服务端内存会话的远程 HTTP。兼容 SDK 支持的现代与旧版握手，不承诺未实测客户端全部兼容。
- 公告学校/搜索/正文、收藏列表/增删、提醒列表/加入/设置/移除/日历导出；结构化数据、分页、明确来源和权限注解。正文是资料，不是指令。不会调用网站模型、改AI额度、暴露密钥或私有来源。
- OAuth2.1授权码+S256 PKCE、资源受众校验、短期访问令牌、旋转刷新令牌、公开发现元数据、动态客户端注册；支持可安全取得的客户端ID元数据文档。另提供可撤销的手动Bearer密钥，兼顾支持请求头配置的客户端。
- 个人工作区新增MCP连接页，选择读写范围、查看连接、撤销，密钥仅生成时显示；OAuth由网站显式确认当前匿名工作区和客户端来源。MCP授权不迁移到新设备，也不复用一次性迁移码或浏览器Cookie作为外部凭据。
- 所有凭证及授权码仅存摘要，授权绑定工作区、客户端、资源、权限和到期时间；不接受用户传入所有者。90天授权、60分钟访问令牌、5分钟一次性授权码，撤销立即阻止后续请求。
- 写操作必须提供requestId，在同一SQL事务中完成修改和回执，同键不同参数拒绝；并发重试不重复创建。按工作区/授权锁序检查撤销、权限及最新来源许可。
- MCP明确指定学校，不改变网站当前选校；复用收藏和提醒校验，但仅在可信服务端MCP适配中允许跨学校操作。源匿名工作区仅含公开可读资料；旧账号工作区、邮箱绑定/验证、推送订阅、来源编辑和账号管理不开放给MCP。
- 提醒沿用既有FC调度和验证规则，新事项默认站内/日历；额外渠道需用户已在网站开启且工具参数显式选择。授权和工具输出不返回邮箱、推送端点等凭据。
- 新增独立SQL迁移并同步三条历史，旧迁移与紫色模板CSS不改，沿用每日清理，无额外定时器或生产密钥轮换。

## 验证

真实本机SQL验证授权隔离、范围拒绝、过期/撤销、PKCE与资源绑定、授权码单次兑换、刷新轮换/重放、客户端验证、SSRF和重定向边界、写操作原子回执、并发和跨校操作不改网页偏好。官方客户端完成协议发现与工具调用；Inspector及桌面/手机页面检查。新增10个只读固定数据评估用例。完整npm ci、类型、测试、普通和完整Netlify构建；不发送真实邮件/推送或模型调用，不写入生产夹具。
