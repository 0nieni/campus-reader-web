## 页面行为

在 AI 阅读的使用设置内提供服务商列表、添加/编辑/删除、当前服务商与模型选择。

- 每项保存名称、接口协议、HTTPS 接口基础地址、模型 ID 列表与默认模型；最多10项服务商、每项最多20个模型。
- 支持 DeepSeek、OpenAI、Anthropic、Gemini 预设及自定义接口。协议分别适配 Chat Completions、Responses、Anthropic Messages、Gemini GenerateContent；预设只是可修改的填写起点，不宣称账号必有某个模型。
- API Key 输入使用密码框。保存后清空输入，只显示“已保存”，编辑时留空表示保留原密钥；改变接口地址或协议必须重新输入密钥，避免误送旧密钥。
- “保存”和“使用此配置”分开。选定的服务商和模型按账号保存，刷新后恢复；切换仅影响之后新发起的轮次。
- 官方 AI 入口保留。个人服务商失败时显示错误，不自动切换到官方模型或另一服务商，不额外消耗官方额度。
- 删除当前服务商后清除个人选择，并要求用户明确选择下一服务；删除不触发模型请求。
- 保存、切换和列出配置不调用模型。真实连接测试和模型用量须由用户后续明确点击并验收，本轮开发只使用测试桩。

## 数据与执行边界

新增独立 SQL 迁移 `20261024000300_ai_provider_profiles.sql`，保留现有迁移原文。所有配置读写和选择均从可信登录身份取得 owner，不接受浏览器指定账号。

- 密钥使用 AES-256-GCM 加密，随机 nonce，附加验证数据绑定 owner、配置 ID 和版本；密文与主密钥分开保存。
- 新增服务端环境变量 `AI_PROVIDER_ENCRYPTION_KEY`，要求32字节随机密钥的 Base64 编码。缺失时明确显示“个人配置保存待启用”；不落盘明文，不借用已有模型或邮件密钥。
- API 只返回名称、地址、协议、模型、版本和是否保存密钥；不返回密钥、密文、认证头或服务商原始报错。
- 既有临时 DeepSeek/OpenAI BYOK 保持兼容；新保存配置通过配置 ID 和版本解析密钥，不把密钥写入任务、对话、导出或日志。
- 空密钥编辑需要先用旧版本 AAD 解密，再以新版本 AAD 与新 nonce 加密。不能把旧密文直接复制到新版本。
- 自定义地址只允许公网 HTTPS，无账号口令、查询串或 fragment；请求前检查 DNS 并固定公网地址，不跟随重定向，保留超时、大小和响应格式限制。
- 创建轮次固定配置 ID、版本、协议、模型和接口指纹。每批请求前与接受结果前检查配置仍有效；编辑/删除后旧任务明确停跑，不静默更换密钥或接口。新的当前项选择不影响旧轮次。
- 配置固定发生在检索前的轮次占位时；同 requestId 不从当前选择重新求值。版本锁与批次领取、结果提交协调；已发出的外部请求无法撤回，配置改变后丢弃其返回。已完成结果仍按原对话期限读取；失效任务保留取消和核查入口，并释放聊天占位。
- 初版沿用既有公网 IPv4 固定策略，IPv6-only 接口不在已验证范围。收到非成功 HTTP 状态立即终止连接，不持续读取不受控错误响应。
- 现有官方每日账户、预占、幂等、状态未知暂停、资料授权及24小时对话期限继续生效。
