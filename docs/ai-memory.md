# 自动用户记忆

2026-10-22。本地实现，真实模型重要性判断待实测。

自动记忆默认开启，AI自行判断当前用户明确说出的信息是否重要、是否对后续推荐或目标推进有帮助；无需逐条确认。它与用户手填偏好、行为学习、聊天记录分开。行为学习仍默认关闭；聊天依旧创建满24小时到期，长期记忆不会延长聊天或保留完整历史。

## 保存内容

首版每个账号、每所学校最多六条，每个槽保存最新事实，每条最多180字符。当前问题与手填偏好优先，记忆不证明用户具有某种资格或审核通过。

| 槽 | 内容示例 | 保留 |
| --- | --- | --- |
| major | 用户明确说出的专业 | 到删除或新自述替换 |
| year | 当前年级 | 最多365天 |
| interests | 稳定兴趣 | 到删除或新自述替换 |
| response_style | 长期回答偏好 | 到删除或新自述替换 |
| goal | 当前重要目标 | 最多180天 |
| progress | 已完成或进行的阶段 | 最多30天 |

到期立即停止读取/使用，沿用每日清理对最多200份档案轮转删除过期正文，不承诺准点物理删除。只保留不含正文的每槽时间水位，用来拒绝迟到旧观察。重复表述推进观察水位，但不续期或反复增加内容版本；新内容按其观察时间更新，较旧回调不能覆盖较新表述。

临时查时间/材料、问句、假设、引用、他人经历、公告正文和助手自己的推断不存为用户事实；密钥、密码、证件号码、联系方式等不存。用户本轮说不要记住时不提取。程序会保守拒绝不符合规则的候选，不能保证每个有用信息都被识别。

## 对话流程

1. 服务端按可信身份和当前学校读取有效记忆，放入独立背景，最多六条，不挤占近期问答的3500字符预算；整体仍受已有模型输入上限限制。
2. 模型先正常回答，最多在同一次最终输出中提出两条记忆候选，格式由[阅读指南](ai-reading-guide.md)规定，不额外调用模型或消耗一个官方轮次。
3. 候选必须有当前用户问题中的逐字证据，text与evidence完全一致。服务端白名单、长度、来源、开关和观察时间校验通过，且回答成功完成、来源/引用校验通过后，才自动保存。
4. 隐藏元数据在正文校验前剥离，不显示在消息、导出或后续历史里。畸形格式丢弃候选，不以候选数据作为公告事实。
5. 记忆写入或附加读取失败不隐藏已成功的回答；页面独立显示暂未更新提示，刷新对话状态可重试保存，不能重复调用模型。

没有可用公告正文、程序直接返回且没有调用模型的轮次不做AI记忆提取。旧高级报告不提取新记忆。真实模型可能漏提取、误判重要性或输出错误格式，必须结合真实评测观察，不能用桩测试宣称识别准确。

## 管理与隔离

“AI记住的信息”提供列表、删除、清空和独立开关，无逐条确认弹窗。关闭保留条目供查看，但停止使用和保存；清空不删除用户手填兴趣/目标，重新开启后只从后续有效对话学习。删除/关闭后刷新推荐，不继续展示基于旧记忆的理由。

数据位于现有 `user_profiles.aiMemory[schoolId]`，不新增表或迁移，不覆盖偏好、收藏、选校或队友字段。公开接口只有 `ai.memory.get/configure/forget/clear`，浏览器不能指定owner、候选、generation或观察时间；模型候选只有内部完成路径能提交。管理操作使用version检测并发，冲突时重新读取，不静默覆盖。

管理操作改变generation。每批发送、模型结果接收和历史选用时重新校验；旧上下文停止使用，旧回调不能让已删记忆复活。正在处理的轮次如有额度预占，沿用取消/核查机制，不因此赠送新额度。来源授权和学校范围仍由程序控制，长期记忆不能覆盖这些检查。

程序推荐只将有效记忆中的兴趣/目标作为手填偏好、本轮问题之后的辅助依据，理由明确标注来自自动记忆；专业和年级不被用来自动断言符合公告资格。
