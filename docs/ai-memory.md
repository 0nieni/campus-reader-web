# 自动用户记忆

2026-10-23。本地实现，真实模型重要性判断待实测。

自动记忆默认开启，AI自行判断当前用户明确说出的信息是否重要、是否对后续推荐或目标推进有帮助；无需逐条确认。它与用户手填偏好、行为学习、聊天记录分开。行为学习仍默认关闭；聊天依旧创建满24小时到期，长期记忆不会延长聊天或保留完整历史。

## 保存内容

每个账号、每所学校保留四个单值背景槽（专业、年级、兴趣、回答偏好），另可同时保留最多三个独立目标，每个目标最多一条关联进展，合计最多十条，每条最多180字符。旧版id=goal/progress的六槽档案继续兼容读取，不需要迁移。当前问题与手填偏好优先，记忆不证明用户具有某种资格或审核通过。

| 槽 | 内容示例 | 保留 |
| --- | --- | --- |
| major | 用户明确说出的专业 | 到删除或新自述替换 |
| year | 当前年级 | 最多365天 |
| interests | 稳定兴趣 | 到删除或新自述替换 |
| response_style | 长期回答偏好 | 到删除或新自述替换 |
| goal | 最多三个独立目标 | 每个最多180天 |
| progress | 各目标已完成或进行的阶段 | 最多30天，且不超过所属目标期限 |

到期立即停止读取/使用，沿用每日清理对最多200份档案轮转删除过期正文，不承诺准点物理删除。只保留不含正文的条目时间水位，用来拒绝迟到旧观察。重复表述推进观察水位，但不续期或反复增加内容版本；新内容按其观察时间更新，较旧回调不能覆盖较新表述。

临时查时间/材料、问句、假设、引用、他人经历、公告正文和助手自己的推断不存为用户事实；密钥、密码、证件号码、联系方式等不存。用户本轮说不要记住时不提取。程序会保守拒绝不符合规则的候选，不能保证每个有用信息都被识别。

## 对话流程

1. 服务端按可信身份和当前学校读取有效记忆，按当前问题选取相关目标及进展，固定背景仍可带入；没有目标明确匹配的泛问可带最多三个目标。不挤占近期问答的3500字符预算；整体仍受已有模型输入上限限制。
2. 模型先正常回答，最多在同一次最终输出中提出两条记忆候选，格式由[阅读指南](ai-reading-guide.md)规定，不额外调用模型或消耗一个官方轮次。
3. 候选必须有当前用户问题中的逐字证据，text与evidence完全一致。服务端白名单、长度、来源、开关和观察时间校验通过，且回答成功完成、来源/引用校验通过后，才自动保存。
4. 隐藏元数据在正文校验前剥离，不显示在消息、导出或后续历史里。畸形格式丢弃候选，不以候选数据作为公告事实。
5. 记忆写入或附加读取失败不隐藏已成功的回答；页面独立显示暂未更新提示，刷新对话状态可重试保存，不能重复调用模型。

没有可用公告正文、程序直接返回且没有调用模型的轮次不做AI记忆提取。旧高级报告不提取新记忆。真实模型可能漏提取、误判重要性或输出错误格式，必须结合真实评测观察，不能用桩测试宣称识别准确。

## 多目标与聊天内管理

新目标分配稳定id，不再让“准备实习”直接覆盖“参加竞赛”；已有目标通过goalId更新。进展携带所属目标的goalId，多目标下归属不明不保存为任意目标进展。达到三个目标时不静默挤掉现有目标；用户可以明确删除/修改后再表达新目标。删除目标连同其进展移除，过期目标不继续提供其进展。

明确指令由程序直接执行或澄清，不经过模型，不需要公告正文，不消耗官方轮次，额度用完或模型未配置时仍可发送。例如“忘掉我的专业”“清空自动记忆”“我现在不准备考研了”“把目标考研改成准备实习”。命令仅作用于自动记忆；手填关注点保持独立。关闭自动记忆后仍允许删除，但不会借纠正指令重新保存新内容。

命令不能用假设、他人说法或引用触发，否定命令不会执行。多个候选目标或指向不清时给出必要的澄清，不擅自删除；只对已执行操作报告完成。请求编号幂等，重复提交不会把后来新学到的内容再删除。内部命令回执保存48小时（超过有效会话24小时），保留请求摘要及结果，不另存问题正文；过期回执在读取/变更和既有每日清理中排除/删除，不按条数提前挤掉仍有效的回执。明确纠正和删除推进generation，旧摘要/上下文及迟到回调不能恢复旧值；明确忘记的条目当前不存在时也建立此隔离，但反馈不声称删除了不存在的内容。

## 较早对话摘要

近期三轮问答仍在3500字符的背景预算内；另从更早且已完成、授权有效的问答生成最多1200字符的摘录摘要。摘要由程序选择原文片段，优先保留决定与待办，并标明可能遗漏/截断，不增加模型调用。它不能代替本轮公告正文或把旧引用编号当作新证据；相关来源依赖仍在每批发送和接受结果前复核；被回答间接引用的记忆依赖也随实际保留的近期问答和摘要传递，到期或纠正后不能通过后续回答间接恢复。

较早问答所带记忆被删除、纠正或到期，或来源失效时，不再进入摘要。摘要保存在原会话/任务上下文中，随会话创建满24小时拒读和既有日清理移除，不转成长期记忆。当前用户纠正优先于较早摘录，不能假装摘要覆盖所有历史。

## 管理与隔离

“AI记住的信息”提供列表、删除、清空和独立开关，无逐条确认弹窗。关闭保留条目供查看，但停止使用和保存；清空不删除用户手填兴趣/目标，重新开启后只从后续有效对话学习。删除/关闭后刷新推荐，不继续展示基于旧记忆的理由。

数据位于现有 `user_profiles.aiMemory[schoolId]`，不新增表或迁移，不覆盖偏好、收藏、选校或队友字段。公开接口只有 `ai.memory.get/configure/forget/clear`，浏览器不能指定owner、候选、generation或观察时间；模型候选只有内部完成路径能提交。管理操作使用version检测并发，冲突时重新读取，不静默覆盖。

管理操作改变generation。每批发送、模型结果接收和历史选用时重新校验；旧上下文停止使用，旧回调不能让已删记忆复活。正在处理的轮次如有额度预占，沿用取消/核查机制，不因此赠送新额度。来源授权和学校范围仍由程序控制，长期记忆不能覆盖这些检查。

程序推荐只将有效记忆中的兴趣/目标作为手填偏好、本轮问题之后的辅助依据，理由明确标注来自自动记忆；专业和年级不被用来自动断言符合公告资格。
