# 网站公告来源导入

2026-10-18：参照小程序运营页新增、测试、启停与采集的操作方式，迁移到当前Netlify网页。原小程序及CloudBase数据不改动，不自动认领或复制其中私人来源。

登录后进入“公告来源”，当前学校由公告页选择。新增来源需填名称、公开入口网址、类型、标签、最短采集间隔，确认站点允许采集；保存后先“测试连接”，核对预览标题，再“立即采集”。支持网页列表、单篇网页、RSS/Atom、JSON公开接口。可编辑解析配置、标签与AI使用许可，启停或移除；更换网址需重新添加。

普通网页默认复用已验证CMS通用规则；其他结构可在高级解析设置填写listItem、detailLink、title、content、publishedAt。JSON默认读取data.list或根数组，字段可配置。只能读取入口同一主机的公开链接，不自动登录、不执行JS或绕过访问验证。正文无法识别时保留原文入口并明确说明；不承诺所有网站均可自动接入。JSON和RSS正文清除脚本，图片和附件不自动识别。日期缺失保持未标注，已有明确旧日期的公告不重新当作新公告导入。

每个账号最多20个自定义来源；个人导入内容按可信UID、所选学校和来源独立，不共享给同校其他用户。稳定ID去重，重新采集保留已有正文、发现时间和个人标签；移除会停用来源并将导入公告下架，保留记录用于防重与授权撤销。采集中编辑、停用或移除会让旧请求停止发布。手动“立即采集”遵守15～1440分钟的最短间隔，不新增定时任务，不代表后台全天候自动轮询。

抓取复用DNS公网上行校验与固定IP连接，验证每次跳转；拒绝内网、特殊地址、凭据和带令牌网址。同一主机请求间隔至少1.5秒，遵守robots.txt与明确拒绝路径；有更长crawl-delay时不自动接入。robots只缓存一小时，404视为未提供规则，其他规则读取失败不绕过。每账号每天最多60次来源请求（含测试、采集和未缓存正文读取），不混入AI额度。

取消上一版全部免费摘要：不再生成、不返回、不展示旧免费摘要，不启动后台补摘要队列，旧school.summarize操作也不开放。列表保留标签旁的来源信息，并提供“用AI生成摘要”入口。点击后只进入已有AI阅读页面，用户先预览再明确开始，不因打开页面、测试或采集而调用模型。摘要与提纲、问答共用每账号每天三次官方额度，北京时间零点重置，同一任务分批只计一次；BYOK仍可选。AI结果仍仅本人可见，沿用24小时清理。

新增接口和存储均复用现有Netlify API及sources/items/user_profiles/school_sync，不新增数据库迁移、环境变量、函数或付费服务。145项本地测试（前端57/后端88）、类型检查与Netlify发布构建通过；验证使用公开格式样例、真实本地SQL和模型桩，未读取线上账号记录或调用真实模型。
