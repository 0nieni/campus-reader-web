# 公告来源中心与网站导入

## 所有来源的统一操作与手动尝试（2026-10-27）

全部来源、已勾选来源管理、学校目录和个人来源均显示“查看原站”“查看该来源下公告”“更新来源”。共享来源需先勾选后查看公告或更新；缺少入口时说明不能更新，个人停用/冷却状态及跨校只读限制继续生效。已接入的学校/公共/个人来源仍走各自已有刷新流程。

尚未验证的公共来源也能通过“更新来源”发起一次手动识别。仅按服务端目录中的现有来源ID取得公开网址，复用通用列表、单篇、RSS/XML和JSON解析；不接收任意网址或选择器。成功后公告进入现有公共资料库，重复采集防重且不延长原资料保存期。失败保存检查时间和原因，包括动态网页未取得内容、没有匹配公告结构、原站拒绝/robots限制、文件入口类型不支持等；不取消勾选、不删除旧公告，也不将失败页面作为公告导入。

手动尝试沿用每日60次来源请求预算与来源锁、原站规则及冷却。仅打开目录、勾选竞赛和筛选不会发起采集。手动成功不自动加入定时任务；既有已验证竞赛仍按原有每日订阅规则更新。目录条目始终保留，尚未尝试的状态和已尝试失败/成功状态分别展示。下方旧版“未验证来源不显示采集按钮”及“只允许已验证ID手动采集”的说明以本节为准。

## 已勾选来源管理与学校首次采集（2026-10-26）

“管理我的来源”显示当前阅读学校下已勾选的学校/公共来源，并继续显示本人添加的全部来源。共享来源保留原站、状态、查看公告和已接入的采集操作；取消勾选后退出该列表，可在全部来源中重新选择。本人添加的来源继续单独提供编辑、测试、启停及移除。这里的勾选按账号和阅读学校保存。

当前学校中尚无采集记录的已配置栏目，首次勾选（包括全部勾选）后采集一次；选择先保存，采集失败保留选择并明确提示。重复勾选不重复首次采集，手动刷新仍遵守原有来源锁及冷却。其他学校的选择只保存，切换为当前学校后使用既有读取流程。学校来源和已明确订阅的学校沿用北京时间02:45每日更新；明确订阅不再受普通30天访问窗口限制。需要已有的服务端Lexmount配置和MATERIALS_JOB_SECRET。

北京交通大学主站、本科生院及计算机学院接入同一学校采集器，旧来源ID/历史资料继续使用；主站旧来源与目录来源通过固定别名共同匹配公告，选择仍分别保存。其余竞赛链接的收录与接入状态不变，未接入的链接即使勾选也不会自动产生公告。下方历史“勾选不触发采集”的描述对学校首次勾选以本节为准，浏览与筛选始终不采集。

## 来源中心（2026-10-24，已同步 AI_module，线上效果待验证）

侧边栏“公告来源”统一进入来源中心，顶部显示当前阅读学校，下分“学校来源”和“我的来源”。学校目录使用已有配置，本轮不寻找或补充新来源。

“学校来源”默认查看当前学校，可按学校名称搜索并浏览其他学校的公开来源。卡片显示栏目名称、所属学校、覆盖范围、原站入口和已有检查结果。已配置与可读取分别展示；缺少有效记录、缓存版本与当前解析/来源配置不符，或检查尚未完成时，显示“尚未检查”，不以学校目录的 ready 状态冒充来源可读。已有成功/失败记录显示最近检查日期、读取数量及说明，不承诺实时可用或所有正文和附件可读。无来源时仍保留学校官网入口。

浏览学校只改变页面目录，不修改账号选校，不刷新网站。用户明确点击“切换到该校并查看公告”后，复用已有选校和公告加载流程；失败保留原阅读学校并提示。当前学校提供“查看公告”和“刷新本校公告”，刷新受既有一小时缓存及失败冷却限制。切校清空旧公告选择，AI沿用既有学校隔离。旧切校请求完成后不覆盖用户后续导航；换账号或退出时丢弃旧页面结果。

新增可信登录的只读 `school.sources` 操作：输入 `{schoolId}`，返回 `SchoolSourceCatalogue`（学校、覆盖说明、稳定来源ID、名称、URL、检查状态/时间/数量/说明）。允许查看目录中其他学校，服务端只读取公开配置与已有 school_sync 记录，不访问目标网站、不写数据库、不返回解析选择器或个人来源。`school.list`、`school.select`、`school.refresh` 与个人 `sources.*` 接口沿用原契约；跨校只读目录不放宽公告、个人来源或AI权限。

“我的来源”仅管理当前学校的本人来源，支持名称搜索和启用状态筛选，并显示来源类型、分类、AI许可、最近成功采集日期与上次数量。测试只预览，采集才导入。切换两个页签会保留个人表单及在途操作，采集完成仍通知公告列表失效；停用保留已有公告，移除二次确认后隐藏导入公告。高级解析默认折叠，不新增后台采集调度、SQL迁移、密钥、收费服务或跨校聚合。

当前检查证据及真实联调限制见根目录 PROGRESS.md。浏览器验证使用独立 output/playwright 模拟入口，不加入生产网页或数据库。

### 在主页公告中显示

学校来源和个人来源的每张卡片提供独立的“在主页公告中显示”开关，默认开启。保存成功后生效，失败恢复原勾选并提示。该选项只控制本人主页公告列表，不等同来源启停，不停止采集、不下架数据、不撤销收藏/详情/AI读取权限。隐藏的来源仍可在来源中心查看和重新开启；查看外校时也可以设置该校来源，不改变当前阅读学校。

操作 `sources.feedVisibility` 接收 `{schoolId,sourceId,visible}`，服务端从可信会话取得数据归属，验证布尔值、学校及来源标识。只允许现行内置来源或本人在对应学校未移除的个人网站来源，不能修改他人私有来源。`school.sources` 和 `sources.list` 返回 `showInFeed`，缺失时按显示兼容。

设置复用 `campus_documents` 的本人 `user_profiles.hiddenFeedSources[schoolId]`，仅保存隐藏来源ID；单条SQL原子合并该字段，保留选校、自动记忆、收藏及其他学校设置，重复保存不产生重复ID，不新增迁移。主页服务端在SQL分页前排除隐藏来源，并在网关再次校验；AI内部候选查询不使用这个显示过滤条件，既有来源授权继续独立执行。

成功写入后的缓存失效由稳定App层处理，按操作学校清除已有页缓存：当前学校重载列表，外校仅清缓存，切校后再加载。即使保存时离开来源页面仍可失效；身份世代变化后忽略旧回调，不影响新账号。显示设置不清空已选AI资料，不重复刷新页面。真实登录/远端状态仍须单独联调，本地浏览器使用模拟传输，持久化/隔离/分页以真实本地SQL测试验证。

### 批量设置、单来源查看与采集反馈（2026-10-24，本地实现）

来源中心顶部的批量设置始终针对“当前阅读学校”，覆盖该校现行内置来源和本人未移除的个人网站来源；浏览其他学校不会改变这个目标。`sources.displayState({schoolId})` 返回 `{total,shown,hidden}`，`sources.feedVisibilityAll({schoolId,visible})` 在一次SQL中合并该校档案字段，不逐条提交，不改其他学校、其他账号或共享来源。没有来源时禁用批量按钮。单项操作、批量保存及批量后的个人列表重载共享忙碌状态，防止旧响应覆盖新设置；保存失败保留原值与统计。

每条学校/个人来源提供“查看该来源公告”。先复用现有切校流程，再通过 `feed.list` 的可选 `sourceId` 在SQL分页前精确筛选；与关键词、标签和时间筛选组合。主动查看已隐藏的来源时，仅此次精确来源查询不套用该来源的主页隐藏偏好，页面明确提示“主页显示设置不变”，不写回显示设置，不放宽账号、学校、来源权限。可清除单来源筛选；切校清除旧来源编号，内存缓存按来源分别分键。

`feed.list` 有隐藏偏好时返回可选 `hiddenSourceCount`，零时省略以兼容旧消费方；前端按账号和学校缓存并在退出、切校、来源设置变更时更新。主页空列表提示关闭了多少来源并提供“管理来源”；只提示设置存在，不声称空列表一定由隐藏造成。

学校与个人来源的诊断按服务端结构错误码提供建议，区分登录/校园网入口、访问验证、robots拒绝、解析失败、入口失效、冷却和请求上限。一般网络错误明确原因未知，不凭连接失败断言必须使用校园网。原站入口持续可用，不代为登录或绕过限制。

学校刷新和个人采集返回/保存 `SourceCollectionStats`，包含 `newCount`、`existingCount`、`failedSources`、`skippedCount`。新增与已有按稳定公告ID核对，学校按本轮成功栏目汇总、失败计栏目数；个人采集在持有来源锁的事务中计数，跳过过期记录另列。失败次数是来源数，不能当作失败文章数，列表成功不保证逐篇正文/附件可用。旧记录缺失统计时不伪造明细，下一次实际采集才产生统计。卡片用北京时间显示日期和分钟；个人来源显示 `nextRefreshAt`，冷却期间禁用立即采集，到期自动恢复按钮；仅更新界面时钟，不启动后台采集。

## 个人来源接入规则

2026-10-18：参照小程序运营页新增、测试、启停与采集的操作方式，迁移到当前Netlify网页。原小程序及CloudBase数据不改动，不自动认领或复制其中私人来源。

登录后进入“公告来源”，当前学校由公告页选择。新增来源需填名称、公开入口网址、类型、标签、最短采集间隔，确认站点允许采集；保存后先“测试连接”，核对预览标题，再“立即采集”。支持网页列表、单篇网页、RSS/Atom、JSON公开接口。可编辑解析配置、标签与AI使用许可，启停或移除；更换网址需重新添加。

普通网页默认复用已验证CMS通用规则；其他结构可在高级解析设置填写listItem、detailLink、title、content、publishedAt。JSON默认读取data.list或根数组，字段可配置。只能读取入口同一主机的公开链接，不自动登录、不执行JS或绕过访问验证。正文无法识别时保留原文入口并明确说明；不承诺所有网站均可自动接入。JSON和RSS正文清除脚本，图片和附件不自动识别。日期缺失保持未标注，已有明确旧日期的公告不重新当作新公告导入。

每个账号最多20个自定义来源；个人导入内容按可信UID、所选学校和来源独立，不共享给同校其他用户。稳定ID去重，重新采集保留已有正文、发现时间和个人标签；移除会停用来源并将导入公告下架，保留记录用于防重与授权撤销。采集中编辑、停用或移除会让旧请求停止发布。手动“立即采集”遵守15～1440分钟的最短间隔，不新增定时任务，不代表后台全天候自动轮询。

抓取复用DNS公网上行校验与固定IP连接，验证每次跳转；拒绝内网、特殊地址、凭据和带令牌网址。同一主机请求间隔至少1.5秒，遵守robots.txt与明确拒绝路径；有更长crawl-delay时不自动接入。robots只缓存一小时，404视为未提供规则，其他规则读取失败不绕过。每账号每天最多60次来源请求（含测试、采集和未缓存正文读取），不混入AI额度。
