# 匿名工作区与一次性迁移

分支 `codex/anonymous-workspace-transfer` 的本地实现，尚未合并或发布。Netlify 默认采用匿名工作区；保留原 CloudBase 认证兼容路径。

## 使用方式

打开网页即可浏览公告，在“个人工作区 → 我的学校”选择学校。学校、收藏、个人标签、来源显示选择和提醒按本设备的匿名身份保存。匿名身份编号仅用于区分工作区，不能用于登录或恢复数据。

点击“AI 阅读”或“登录以使用 AI”后登录或注册。登录只解锁 AI，继续当前匿名工作区；退出 AI 账号也保留本设备的匿名数据和推送。模型配置、API Key、对话、记忆和官方每日额度仍按真实账号独立保存。

换设备时：

1. 在原设备打开“个人工作区 → 匿名身份”，生成并复制一次性迁移码。
2. 在新设备打开同一网站，进入上述页面，粘贴迁移码并点击“导入并使用”。无需先登录 AI 账号。
3. 导入学校、收藏、个人标签、来源显示选择和提醒；原设备数据保留。新设备阅读学校采用导入学校，收藏与提醒按学校和公告去重，目标已有标签和来源选择优先。
4. 在提醒中心重新填写或验证本设备的收件邮箱，验证后主动开启邮件，再逐篇选择发送方式。设备推送需单独开启；源设备的邮箱证明和推送订阅不会复制。

迁移码30分钟有效，导入成功后不能再给其他工作区使用。同一目标的成功请求重试返回原回执，不重复导入或再次重置邮箱。每个源工作区只有一个有效码；重新生成会作废旧码，也可主动撤销。关闭设置窗口后不再显示原码，需撤销或重新生成。请私下传给自己的设备。

只复制公开且仍可读取的公告引用；失效和私有资料跳过。历史通知、AI账号、API密钥、聊天、记忆、已验证邮箱和浏览器推送订阅不迁移。已过去的提醒时间转为待设置，未来时间保留，导入事项的邮件和推送通道默认关闭。

匿名身份保存在当前浏览器的网站 Cookie 中，设备凭证有效期为一年。清除网站数据、无痕窗口、切换浏览器或凭证失效会进入新身份；匿名编号不能找回原数据。换设备前应先在仍可使用的原设备生成迁移码。

## 原账号数据

为保留过去按账号保存的学校、收藏、提醒与私人来源，已登录用户可在“个人工作区 → 账号安全 → 打开原账号工作区”进入 `/?workspace=account`。该模式显式使用原有账号命名空间，退出后需重新登录。通过“返回匿名工作区”回到默认模式。两个工作区不会自动合并，AI登录不会把账号阅读数据写入匿名工作区。

## 邮箱提醒

匿名用户填写提醒收件邮箱，先保存，再主动发送验证邮件。继续使用既有 DirectMail、独立确认页和阿里云 FC 调度；验证不自动启用发送。更换邮箱或导入迁移码会使目标工作区的验证失效并关闭邮件。已有账号工作区仍使用可信 Identity 邮箱并在后台发送前复核。

沿用每日全站150封、每工作区20封、每工作区验证3封和60秒间隔；匿名地址另有跨工作区同一收件邮箱每天3封验证限额。预览无真实发送器，不发送真实邮件。

## 实现与部署边界

- 独立 SQL 迁移 `20261027000100_anonymous_workspaces.sql` 同步默认、PR14、PR17三条历史。原迁移不改，不在请求内建表。
- 新增 `/.netlify/functions/guest`，同源 POST、参数白名单、请求体大小限制、无缓存。设备凭证为32字节随机值，只存摘要，放在 `__Host-campus-guest` 的 Secure、HttpOnly、SameSite=Lax Cookie 中；可见编号不授予访问权限。
- 迁移码同样使用32字节随机值并只存摘要。目标工作区及兑换记录在 SQL 事务中锁定，白名单合并、邮箱失效和消费回执一起提交。上限超出则整笔回滚，原码仍可用。
- 单次源数据上限500收藏、100提醒、1000标签、200所学校来源设置；导入后目标上限500收藏、100提醒、2000标签。每工作区每分钟1次、每天20次生成，每15分钟30次有效格式兑换尝试；工作区创建全站每天2000次、同地址每小时60次。
- 默认 API 仅开放公开阅读与匿名资料操作；AI要求真实 Identity，私人来源编辑要求显式原账号工作区。客户端提供的UID、所有者、凭证或任意URL不作为授权依据。
- AI仅投影当前匿名选校给本次请求的学校检查；真实账号负责额度、密钥和AI数据，未改写账号原学校。资料下载也区分匿名与显式账号模式。
- 沿用每日清理任务，分批清理过期设备凭证、限额和迁移回执，不新增定时器。代码不会自动删除原设备资料。

部署时应先应用该独立迁移，再发布包含12个函数的完整构建。无需新增模型、邮件或加密配置，不轮换现有生产加密密钥。本分支当前只做本地构建和合成数据验收，不代表生产迁移、真实邮件、设备推送或真实模型联调已完成。
