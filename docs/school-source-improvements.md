# 公开学校来源补充（2026-10-18）

## 实现

`apps/cloud/src/school-sources.ts` 保存维护者核对的官方公开栏目。34 所学校补充或替换来源，支持每校最多三个栏目并行读取；其余学校继续使用用户目录中的入口。北大使用教务部近期通知；清华使用统计与数据科学系通知和心理与认知科学系学术活动，明确不代表全校内部公告。浙大、东南、苏大等补充具体院系/部门的公开栏目；陕西师大改用教务处，西藏大学补充学生工作部和研究生招生通知。

选校后的来源区域显示栏目名称、原站链接、覆盖范围、列表读取结果和失败说明。目录原始入口仍可查阅。栏目列表可用与文章正文可用分别判断；正文为图片/附件、要求登录、验证码或无法解析时保留原文入口，不伪造正文、不发送空资料给 AI。

解析支持 VSB、WebPlus、不透明文章编号、PHP 公告参数、TRS 日期编号链接、标题与摘要分离以及拆分年月日。公开正文的 form 容器保留，只排除表单控件；优先取正文专用容器，排除脚本、CSS、菜单和未填充模板。发布日期仅从日期元数据读取，不从标题中的截止日期或当前年份推断。日期不完整会明确计数。

公共缓存一小时，失败冷却五分钟；来源/解析版本变更后旧完成缓存失效，未过期执行锁不被其他版本抢占。栏目部分失败时保留成功结果与已有公告。最多两次批量数据写入替代逐篇数据库请求，保留正文缓存和原发现日期。个人标签独立保存，不受采集影响。

不执行网站 JavaScript，不自动识别图片或附件，不带用户 Cookie 或学校账号，不绕过登录/VPN/访问验证，不关闭 TLS 检验。URL、重定向、DNS 公网地址、九秒期限和 1.5MB 大小限制继续执行。配置只来自服务端常量，前端不能传采集域名。登录只刷新所选学校，不遍历全目录或创建后台保活。

## 本地和公开源验证

2026-10-18 对 115 校当前配置进行有界公开检查：118 个栏目中 117 个识别出列表，覆盖 114 校；102 个栏目的首篇正文通过读取。只证明检查时这些样本可读，不代表全部文章、Netlify 出口网络或校内内容均可用。其余正文样本包含图片、附件、登录入口与临时连接失败，未按成功处理。中国政法大学主站、教务/研究生及新闻/招生子站均触发访问验证，仍明确不可自动读取。

诊断脚本在本地 `qa/verify-school-sources.ts`，公开 HTML 与完整结果保存在被忽略的 `.migration-private/source-audit/`，不随站点发布，也不读取在线用户资料。首轮原始目录检查仅 83 校识别列表；后续统计使用修正后的解析器和来源配置。

类型检查、前端 45 项与后端 79 项测试通过，含真实本地 SQL 的多来源部分成功、缓存版本失效/执行锁、正文与个人标签保留、跨校拒读，以及浏览器组件的安全链接/覆盖范围显示。Netlify 模式构建、四函数打包与未登录产物拒绝检查通过。没有真实模型调用。

## 发布与维护

通过现有私有 GitHub 仓库的 PR 预览和 main 自动发布。本次无需新表或迁移，不改已应用迁移、账号设置、环境变量、收费套餐或 AI 超时。线上登录后实际来源响应仍以页面状态为准。

维护时先从学校官方导航确认公开栏目和文章，再调整 `school-sources.ts` 的名称、范围、URL 与必要选择器；更新解析器须修改版本标识并补充相关 fixture。不得因为只识别到菜单链接就标为成功，也不把搜索引擎缓存代替实时可读正文。后续若原站更换结构或限制访问，页面会保留失败状态和原站入口。
