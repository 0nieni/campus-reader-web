# AI 全网搜索实施范围

2026-10-24。用户确认：由 AI 搜索整个公开互联网并列出来源，使用 DeepSeek 官方 Search / Fetch，单独在 `codex/ai-web-search` 实现。基线 `b6e383f`。个人服务商保存/切换的未完成工作留在另一个工作区，不纳入本分支。

## 实现

- AI 阅读增加“联网搜索”开关，默认关闭；开启后让 DeepSeek 通过工具调用决定是否搜索及搜索词。关闭时保留既有阅读、学校搜索和官方额度流程。
- 只连接 DeepSeek 官方模型及 Search/Fetch 固定 HTTPS 端点，使用本轮 DeepSeek Key，不向其他域名发送 Key。
- 每轮最终回答最多一次搜索、三个结果正文读取和两次模型请求；选择校园公告时仍先按原有流程分批阅读。每账号沿用每日20次搜索及15秒间隔。搜索/抓取另有供应商计量，不等同每日三次模型回复额度。
- 工具规划仅接收当前问题，不传资料正文、兴趣档案或历史聊天；正文仅进入最后的阅读回答。
- 来源留在本人的本轮任务中，不写入共享公告/自动订阅。区分正文、仅摘要、未读取；仅正文摘录用于事实依据。回答与来源链接校验，未知链接拒绝采纳。
- 无搜索结果、服务未配置、权限/余额/限流/超时明确显示；不把失败冒充“已搜完”，不自动重发模型或改用另一个Key。
- 继续保留可信账号、学校/资料许可逐批重验、24小时过期、任务幂等、未知状态暂停和原官方日账户。

## 使用与部署

进入 AI 阅读，选择 DeepSeek 回答服务，勾选输入框下方“联网搜索”后发送问题。可以直接搜索公开互联网，也可以同时选中校园公告；AI 判断不需要检索时会显示“本轮未联网”。回答下方列出实际取得的来源及读取状态，导出对话也会包含这些来源。

沿用现有 `AI_CHAT_BASE_URL`、`AI_CHAT_MODEL`、`AI_CHAT_API_KEY`，无需增加搜索服务账号或新的环境变量。官方地址须为 `https://api.deepseek.com` 或 `https://api.deepseek.com/v1`（也接受完整 Chat Completions 地址）；选择的模型须支持工具调用，Key 须有 Search / Fetch 权限和可用余额。个人 API 使用本轮临时输入的 DeepSeek Key，仍只保留在页面内存和本次请求中。

当前实现用于现行 Netlify 直接执行架构。旧 CloudBase 签名中继不支持此模式，会在占用额度前明确拒绝；OpenAI 和第三方中转地址不支持此搜索通道。搜索词只生成自本轮问题，不将校园资料正文、历史对话、阅读兴趣发送至搜索接口。网页只读取公开且可访问的内容，登录页、内网地址、附件和检索范围之外的网页均不会被当作已读资料。

开发验证采用合成资料和请求桩，不证明真实 Key 的搜索权限、账户余额或实际搜索覆盖率。上线前在分支预览中以自己的有效 DeepSeek Key 测试一次明确需要最新公开资料的问题；实际供应商请求可能计量。尚未进行生产部署。
