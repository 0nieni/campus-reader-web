## Lexmount 采集

学校与个人 HTML 来源的后台采集接入 Lexmount Web Fetch，保留现有公告解析、附件入库和 365 天资料保存规则。运行前需要服务端 `LEXMOUNT_API_KEY`、`LEXMOUNT_PROJECT_ID`，可选区域入口与引擎配置；不依赖开发电脑的技能登录文件。RSS/JSON、robots 和原文件下载继续保持各自的协议读取。配置、实测及限制见 [Lexmount 采集说明](docs/lexmount-collection.md)。用户已于 2026-10-25 授权合入 main 并发布，实际发布及联调状态以 [进度记录](PROGRESS.md) 为准；部署代码不等于已配置凭据或采集联调成功。

## 采集资料库

公告正文与 PDF、Word、Excel 附件由 Database + Blobs 保存 365 天，读取自动使用有效文本，过期后停止读取并由每日任务删除；仍符合规则的资料可按需重新采集。每日北京时间 02:45 采集近 30 天使用的学校及启用的个人来源；需要新增服务端 `MATERIALS_JOB_SECRET` 才启用每日采集。扫描件保留原文件并显示未提取文字，不进行 OCR。原有提醒功能保持不变。配置、限制和本地验证见[采集资料库说明](docs/material-archive.md)。下文原有“正文按需读取、附件不自动读”的描述为旧版本状态，以本节的新实现说明为准。

## AI 搭子默认每轮联网与个人阅读设置

阅读偏好和“AI记住的信息”统一位于左下角“个人工作区 → 阅读偏好”，包括关注话题、近期目标、行为学习和自动记忆管理；AI 阅读右侧只保留公告与公开资料搜索。已有账号/学校数据和API保持不变，工作区修改后同步刷新AI推荐，记忆删除会停止旧上下文。

AI 搭子默认由程序在每轮提问时先全网搜索本轮问题，只有明确提到本校或学校时才补当前校名，再由模型选择相关网页读取；明确说“不要联网”时除外。取消模型搜索词的公开主题白名单，不附带历史、记忆或资料正文，重复搜索请求复用本轮结果；继续复用后台 DeepSeek Key、20次/日及15秒搜索间隔、官方成功一轮一次用量记录。一步至多一次模型或工具请求，可取消，未知状态不自动重发；本轮先执行1次Search，重复Search复用结果；最多3次Fetch、4次工具阶段模型调用。现有正文分批仍独立受平台预算约束。回答只引用已授权且实际取得的正文，搜索摘要不作证据，临时资料与工具消息随对话固定24小时到期。明确说“不要联网”时不给模型提供联网工具；不支持工具的模型可手动搜索并选入正文，以“不要联网”的问题使用原文本接口。兼容OpenAI Chat/Responses、Anthropic和Gemini协议，实际模型支持仍以调用结果为准。实现与验证见[自动联网方案](docs/superpowers/specs/2026-11-03-assistant-auto-web-tools-design.md)和PROGRESS.md；实际发布状态以已合并版本和部署记录为准。

## Netlify 构建

将此私有仓库连接到现有 Netlify 项目，保留根目录 netlify.toml。Base directory 和 Package directory 均留空：这是包含网页、服务端函数和迁移的一个完整站点，不单独选择 apps/web 作为站点项目目录。构建命令为 npm run build --workspace=@campus/web，发布目录为 apps/web/dist，函数目录为 netlify/functions。全部 SQL 迁移位于 netlify/database/migrations，由平台在部署生命周期应用，不在网页或函数请求中执行建表。可先运行 npm run netlify:build 检查完整函数与网页产物，该命令不会发布。

来源中心默认以统一列表展示本校、公共和个人来源，可按公告相同的七类标签、关键词、来源类型和勾选状态筛选。学校来源默认勾选，其他默认不勾选；公告页的普通列表及单来源查询都仅显示已勾选来源，收藏、详情和 AI 许可继续独立校验。个人来源编辑与其他学校目录浏览仍保留，未新增跨校公告聚合。

用户于 2026-10-26 将范围改为收录导航中的全部链接：203 个有链接的竞赛项目分别展示，196 个不同网址中的重复链接也按项目保留；另 11 项没有链接，不制造入口。目录对所有账号可见，保留导航序号、入口类型及原文件备注，可用相同分类、关键词、勾选状态及新增的采集能力筛选。收录与采集能力分别显示：通过真实 Lexmount 列表和样本正文验证的 4 个栏目支持 5 个竞赛项目独立采集，两项“挑战杯”分别勾选；其余显示“待验证”或“仅原站入口”，不因勾选、浏览或日任务自动访问原站。历史来源及其已保存选择保留。原文件备注不是实时可用性结论。记录见 [全部竞赛链接导入](docs/plans/2026-10-26-all-competition-links.md)。

以下 2026-10-24 的分栏说明保留作历史，默认入口、勾选规则和精确来源筛选以本节及最新来源说明为准。

“公告来源”包含“学校来源”和“我的来源”。可搜索各校并查看已配置的公开栏目、覆盖范围、原站入口及已有检查状态；浏览其他学校不切校、不抓取，明确点击“切换到该校并查看公告”后才进入对应学校。当前学校可手动刷新，内置来源由项目维护者配置，不代表全部校内公告已接入。

每条学校来源与个人来源都有“在主页公告中显示”开关，默认开启，按本人账号和学校保存。关闭后只从本人主页公告列表隐藏该来源的内容，不停用采集、不删除公告，也不改变收藏或AI阅读权限；重新开启即可恢复显示。

来源中心可查看本校开启数量，并一次全部显示或隐藏本校内置与个人来源。主页无结果且有隐藏来源时提供管理入口；“查看该来源公告”支持主动检查单个来源，包括已隐藏来源，并保留主页显示设置。卡片按实际错误说明失败原因及处理建议，显示新增/已有公告数、失败来源数、分钟级检查时间与下次可采集时间。

“我的来源”管理当前学校的个人网页列表/单篇、RSS/Atom和JSON公开接口，支持新增、测试预览、采集、编辑、启停、移除，以及名称和启用状态筛选。自定义来源及内容按账号与学校独立；采集间隔不代表后台定时更新。普通浏览和采集不扣AI次数；摘要、提纲和问答与其他AI对话共用每日额度，仅主动发送才调用模型。此升级已同步到 AI_module，线上版本和真实账号效果仍待单独验证。详见 [来源中心与网站导入](docs/website-source-import.md)。
